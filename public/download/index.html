Versioned releases include platform packages, SHA-256 checksums, release notes, third-party notices, and SPDX software bills of materials.

macOS

Supported: macOS 13 or newer on Apple Silicon and Intel. One universal DMG is signed, notarized by Apple, and stapled.

Linux

Preview: x86_64 AppImage validated on SteamOS. Desktop integration varies across distributions, X11, and Wayland compositors.

Windows

Experimental: unsigned x86_64 installer and portable executable. Windows may show an unknown-publisher warning or block installation.

Homebrew

After the stable cask is available, install the same signed macOS app from the Pasted tap.

brew install --cask getpasted/tap/pasted
