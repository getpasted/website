What happens on the computer stays on the computer

Your business is none of ours.

Pasted is designed around a local library, explicit connections, bounded diagnostics, and useful behavior that does not require an account.

Clipboard data stays local

The core clipboard library is stored in SQLite on the device. Pasted does not host or synchronize a copy of clipboard history.

No product telemetry

The app does not measure engagement, inspect clipboard activity for analytics, or send clipboard contents to a product analytics service.

Optional connections are explicit

User-configured intelligence providers and operations may contact outside services only when enabled and invoked. Their scope and credentials remain visible and controllable.

Sensitive material stays out of Activity

Activity records use neutral identifiers and counts. Clipboard contents, transformation input, credentials, and sensitive file details are excluded.

This website

getpasted.app is a static site hosted by GitHub Pages. Pasted does not install a visitor analytics script, advertising tracker, or tracking cookie. GitHub states that Pages visitor IP addresses are logged for security purposes under GitHub’s own privacy practices.
