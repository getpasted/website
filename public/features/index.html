Everything your clipboard forgot to include

A private clipboard workspace with an excellent memory.

Pasted captures the things copied during real work, makes them searchable and useful, and keeps the core library on the device.

History and search

Find copied text, links, images, screenshots, and file references using full-text search, structured filters, the app, the Quick HUD, or the CLI.

Bins and organization

Pin important clips, arrange manual Bins, and use Smart Bins to gather matching clips without moving or duplicating the underlying data.

Transforms and automation

Reshape text into Markdown or structured formats, chain reusable operations, and run the same shared behavior from the graphical app and scripts.

Local Analysis

Make images and audio searchable with local OCR, visual labels, file inspection, and transcription. Optional engines remain explicit and user-controlled.

Recovery and portability

Use Trash, revisions, Full Backup and Restore, and History and Organization transfer tools without turning a hosted account into a prerequisite.

GUI and CLI parity

The app and pasted command share domain services and one local library, with structured JSON output for scripts, automations, and agents.
