Speak softly and carry a big pipe

The clipboard has a command line.

The bundled pasted executable uses the same local database and shared services as the graphical app. Human-readable output works at a terminal; --json keeps automation stable.

Start with search

pasted search "that thing" --json

Search content and metadata, narrow results with structured filters, and return stable fields for downstream tools.

Capture and retrieve

Save text, list clips, inspect metadata, copy a known clip, and contact the running app for live actions such as Queue paste.

Organize and transform

Manage Bins, tags, protection, notes, Transforms, Operations, and Analysis definitions with the same validation used by the app.

Automate safely

Structured output, bounded payloads, explicit confirmation flags, and content-free diagnostics make the CLI suitable for scripts and agents.

Install

Install the CLI from Settings → About. The macOS Homebrew cask also exposes the bundled executable on the command path.
